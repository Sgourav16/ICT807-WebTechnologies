# CareerCompass AU — Shared Foundation

This package contains the common project standards that all page work should follow:

- `docs/TEAM_DESIGN_SYSTEM.md`
- `docs/SITE_ARCHITECTURE.md`
- `docs/TEAM_CODING_STANDARDS.md`
- `docs/DATA_CONVENTIONS.md`
- `css/shared-base.css`
- `templates/page-template.html`

The purpose is to keep pages visually and technically consistent while allowing different pages/features to be developed separately.

The shared foundation defines common colours, typography, responsive principles, semantic HTML structure, accessibility rules, reusable CSS classes, dataset conventions and the planned ten-page information architecture.

Page-specific content and behaviour can then be added without redesigning the whole system.
