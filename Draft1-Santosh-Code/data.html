Data & Methodology

Understand where the CareerCompass AU information comes from and how it should be interpreted.

SourceJobs and Skills Australia

Primary dataset

Australian Jobs 2026 Occupation Matrix

The prototype uses official Australian labour-market information from the Australian Jobs 2026 Occupation Matrix.

Initial methodology

  1. Retain the official CSV as the primary source.
  2. Load occupation records in the browser.
  3. Present missing values as “Not available”.

Important limitations

Earnings are indicative bands and projected growth is not the same as job vacancies.

National-level figures can hide regional differences, projections can change, and the dataset does not measure competition for every vacancy.

Definitions

Measures used by the website

The website presents employment, earnings, skill level and projected change using the definitions supplied with the source dataset.

CareerCompass AU uses official Australian labour-market information for educational career exploration.
