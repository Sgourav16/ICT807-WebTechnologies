CareerCompass AU dataset folder

The pages first look for the official Jobs and Skills Australia Occupation Matrix CSV using either of these filenames:
  aus_jobs_2026_-_occupation_matrix_0.csv
  aus_jobs_2026_-_occupation_matrix.csv

If neither file is present, occupation_demo.csv is used as a small verified sample.

Official source: https://www.jobsandskills.gov.au/research/australian-jobs
